# Visual design — approval status

**Status: awaiting owner approval (board v1, 24 Nov 2026).** No Android or PWA UI
work starts until this board is approved in writing.

| File | What it is |
| --- | --- |
| `visual-board.html` | The board: direction, palette with measured contrast, type scale, icons, components, five key screens, cross-app (web/PWA) composition, motion/accessibility/policy notes, approval checklist |
| `visual-board.png` | Full-page render of the board (1280 × 7097) for quick viewing or sharing |
| `img/board-*.jpg` | The five screen mockups at 540 px wide |

The screens were produced as original renders for this board; they are placeholders
for direction, not final assets. Brand name and logo remain open (decision D-006),
and the wordmark in the mockups is a placeholder.

Palette contrast ratios quoted on the board are computed from the hex values
(body text 16.34:1, muted text 8.78:1, ink-on-amber 8.55:1), not estimated.

To review: open `visual-board.html` in a browser, or look at `visual-board.png`.
