Paper,
not plastic.

A subscription platform for adult creators should look like a photographer's catalogue, not a social network. This direction is built from print: bone stock, oxblood ink, hairline rules, a didone face for names and money, and photography that is allowed to run edge to edge. Chrome is deliberately thin so the work, the price and the person carry the screen.

It is a full reconsideration, not a recolour of v2. Different structure (rules and ledgers instead of floating cards), different typography (didone display, grotesque UI, mono for money), different relationship between image and interface, and a brand that exists as a mark and a wordmark rather than an accent colour.

What changed and why

v2 read as generated: every surface was a rounded card, every gap equal, gradients standing in for photography, a serif used decoratively.

v3 is art-directed: one photographic subject, one ink, one rule weight, prices set as type rather than in badges, and empty space used to separate rather than boxes.

Not a template: no borrowed palette or component library; the system is 5 tokens, 3 typefaces and 8 components.

One shoot, many frames

A set is graded, not recoloured: crops, grain and one duotone for anything behind a paywall.

Wordmark and mark
Vesper

The mark is an eclipse: two circles, oxblood and paper. It survives at 16 px, prints in one ink, and never needs a gradient. The wordmark is set in the didone at 0.16 em tracking — the only place type is tracked that wide.

Vesper: the evening star. Adult without being explicit, and it reads as a place rather than a feature.

Four destinations: Home, Library, Create (studio, hidden for non-creators), You. Pushed screens keep one back path; unlocking and confirmation are sheets. Money is never more than one step from the thing it buys.

Before implementation

  1. Does this direction — paper, oxblood, didone, photography — feel like the product?
  2. Is the four-destination bar right, with studio inside Create rather than a fifth tab?
  3. One photographer-voice brand (Vesper) or a neutral platform mark?
  4. Should fans see the fee split, as the statement does, or only the total?
  5. Anything missing before the tokens and shell are built?

No production screen, route, schema or dependency was changed to produce this board. The single photograph is an original generated stand-in; licensed photography is a separate decision.
